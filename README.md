# MultiTone_Email_Generator

This is a practice capstone project for gen ai

.
What you build: A simple command-line or Streamlit app where a user inputs raw bullet points and selects a tone (Formal, Casual, Aggressive, Empathetic). The model rewrites it into a polished email.

Core Concepts Learned: API requests (google-genai), system instructions vs. user prompts, basic UI inputs.

Why it’s easy: Pure single-turn prompt-response with no state or complex databases required.
